# Jerzy Tape Drive VST3

Samodzielny efekt VST3 modelujący tor taśmowy: optyczną kompresję wejścia, preamp, saturację taśmy, wow/flutter, zużycie taśmy oraz filtry wyjściowe.

GUI obsługuje skalowanie i resize hosta, a parametry są przeznaczone do automatyzacji w DAW.

Repozytorium zawiera wyłącznie Tape Drive. MX Analog Delay, Auto Tune i pozostałe wtyczki są rozwijane osobno.
